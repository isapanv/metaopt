## Обзор

MetaOpt - фреймворк, реализующий формальную модель оптимизации конфигураций:

$$\Omega = \langle \mathcal{A},\, \Theta,\, I,\, \mathcal{E},\, \mathcal{G},\, \mathcal{F} \rangle$$

$$S^* = \underset{S \subseteq \mathcal{A},\, |S|=k}{\arg\max} \sum_{l=1}^{p} w_l \cdot f_l(S,\, \theta,\, I) \quad \text{s.t.} \quad g_j(S) \leq 0 \; \forall j$$

где $\mathcal{A}$ — пул компонентов, $I$ — матрица взаимодействий (синергий), $\mathcal{G}$ — множество ограничений, $\mathcal{F}$ — функция многокритериальной оценки.

**Фреймфорк содержит:**

- Шесть метаэвристических алгоритмов (GA, DE, PSO, ACO, SA, HybridDEGA) с единым интерфейсом
- Управление каталогами с импортом из CSV/Excel и визуальным маппингом столбцов
- Редактор матрицы синергий с визуализацией в виде тепловой карты и графа
- Конструктор произвольных задач с настраиваемыми целевыми функциями и ограничениями
- Вычисление значений Шепли для анализа вклада компонентов
- Движок рекомендаций алгоритмов на основе характеристик задачи
- Отслеживание прогресса экспериментов в реальном времени через Server-Sent Events

## Запуск

**Требования:** Docker 24+, Docker Compose v2

```bash
git clone https://github.com/isapanv/metaopt.git
cd metaopt
pip install -r requirements.txt
docker compose up --build -d
```

Доступ через: [http://localhost:5000](http://localhost:5000)

Для остановки:

```bash
docker compose down
```

## Алгоритмы

| Алгоритм | Стратегия | Лучше всего подходит для |
|----------|-----------|-----------------|
| **GA** | Генетический алгоритм — турнирная селекция, одноточечный кроссовер, элитизм | Дискретные задачи с синергиями |
| **DE** | Дифференциальная эволюция DE/rand/1/bin | Стабильность, проекция непрерывного в дискретное |
| **PSO** | Бинарный метод роя частиц | Быстрая начальная сходимость |
| **ACO** | Муравьиный алгоритм с матрицами феромонов | Пространства поиска с графовой структурой |
| **SA** | Имитация отжига с геометрическим охлаждением | Гладкие ландшафты, воспроизводимость при σ = 0 |
| **HybridDEGA** | Последовательно заупскаются алгоритмы DE и GA | Большие пространства с синергетическими взаимодействиями |

Выбор алгоритма автоматизирован на основе характеристик задачи (размер пространства поиска, количество ограничений, наличие синергий, многокритериальная структура).

## Использование

### 1. Создание каталога

Во вкладке "Каталоги" можно создать собственный каталог с пользовательской схемой параметров. Для добавления элементов в каталог реализованы ручное добавление и импорт из CSV или Excel.

```csv
comp_id,name,skill,cost,role
1,Alice,92,120,teamlead
2,Bob,78,90,backend
3,Carol,85,95,ml_engineer
```

### 2. Определение синергий

Добавления попарных значений взаимодействий в матрицу синергий осуществляется через импорт CSV файлов:

```csv
comp_id_a,comp_id_b,value,note
Alice,Bob,2.5,хорошая пара
Alice,Carol,-1.0,конфликт ролей
```

Положительные значения указывают на наличие синергии (взаимное усиление), отрицательные - на антагонизм.

### 3. Построение задачи оптимизации

Во вкладке "Задачи" можно определите целевые функции с весами и ограничения:

пример:

```
Целевые функции:
  - avg(skill)    вес 0.5
  - __synergy__   вес 0.3
  - avg(cost)     вес 0.2   ← минимизируется через низкий вес

Ограничения:
  - sum(cost) ≤ 400
  - tag_required: teamlead     ← все участники должны иметь тег
```

### 4. Запуск эксперимента

Во вкладке "Эксперимент" выбираются задача, алгоритмы, и параметры по которым происходят вычисления. Результаты включают:

- Сравнительную таблицу по алгоритмам (лучший, средний, худший, СКО, время)
- График сходимости с интерактивными подсказками
- Оптимальную конфигурацию с именами компонентов
- Значения Шепли для анализа вклада

## API Reference

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `GET` | `/api/catalogs` | Получить список каталогов |
| `POST` | `/api/catalogs` | Создать каталог |
| `GET/PUT/DELETE` | `/api/catalogs/:id` | CRUD каталога |
| `GET` | `/api/catalogs/:id/schema` | Схема параметров |
| `PUT` | `/api/catalogs/:id/schema` | Обновить схему |

| `POST` | `/api/catalogs/:id/components/batch` | Массовый импорт |
| `PUT/DELETE` | `/api/components/:id` | CRUD компонента |

| `GET` | `/api/custom-problems` | Получить список задач |
| `POST` | `/api/custom-problems` | Создать задачу |
| `GET/PUT/DELETE` | `/api/custom-problems/:id` | CRUD задачи |
| `POST` | `/api/experiments` | Запустить эксперимент |
| `GET` | `/api/experiments/:id/stream` | SSE поток прогресса |
| `GET` | `/api/experiments/:id` | Получить результаты |
| `POST` | `/api/shapley` | Вычислить значения Шепли |
| `GET` | `/api/domains` | Получить список встроенных доменов |
| `GET` | `/api/algorithms` | Получить список доступных алгоритмов |

Полная документация API: [DOCUMENTATION.md](DOCUMENTATION.md)

## Встроенные домены

Четыре домена включены для бенчмаркинга:

| ID | Домен | Компонентов | k по умолчанию |
|----|-------|-------------|----------------|
| `team_building` | Формирование IT-команды | 12 разработчиков (роли, навыки, стоимость) | 5 |
| `cloud` | Облачные микросервисы | 12 сервисов (CPU, память, стоимость) | 4 |
| `production` | Производственная смена | 12 рабочих (навыки, зарплата, смена) | 5 |
| `electronics` | Проектирование электронных систем | 12 компонентов (мощность, стоимость, архитектура) | 4 |
